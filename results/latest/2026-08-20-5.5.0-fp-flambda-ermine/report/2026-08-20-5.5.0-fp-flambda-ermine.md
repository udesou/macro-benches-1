## Data notes / caveats

- **Allocation counters are clean (in words).** Unlike the 2026-07-24 monolith run — where OCaml 5.5.0's `Runtime_events` emitted `EV_C_MINOR_ALLOCATED_WORDS` in *bytes* (~8× inflated) — this run's olly (`0.5.4-12-g3d37a0b`) reports words: measured `minor_words / minor_collections` = **0.99 × the minor-heap size**. So `minor_words`, `promoted_words`, `total_heap_words` and derived metrics are correct in this sweep.
- **`goblint_gen_{default,large}` are absent (38, not 40).** goblint's apron dependency needs `libmpfr-dev`, not installed on ermine (no sudo), so the binary did not build. Everything else in the `default`+`large` ladder ran.
- **Two benchmarks were re-run at N=5 after a timeout fix.** `eio_conc_large` (~128 s) and `pplacer_like_large` (~218 s) exceeded the old 120 s `macro-eio` / `macro-pplacer` suite timeout on this slower ARM host and were SIGKILLed in the first pass; the suite timeouts were raised to 600 s and both re-run to completion.
- **`devkit_htmlstream_{default,large}` were re-run after a build fix.** The devkit build hard-coded an x86_64 `libevent.so` path; ermine is aarch64, so it failed to link. The dune file now resolves the path via `pkg-config` at build time (multiarch), and both rungs build and run.
- **Governor was `performance`.** Absolute wall times are not comparable across result sets taken under different governors or hosts; only within-sweep deltas are meaningful.
- **Host is aarch64 (Neoverse-N1), not x86.** Wall times run roughly 2–4× the monolith (9950X) reference for the same benchmarks; compare deltas within this sweep, not absolute times against x86 runs.
